# custom-dark-background

A Firefox add-on that lets you change the background color to a dark shade of your choice.

Download from [this link](https://addons.mozilla.org/fr/firefox/addon/my-custom-dark-background/).

Works on:
- chatgpt
- github
- gmail
- google
- qwant
- radiofrance
- twitch
- wikipedia (fr)
- youtube

Important for better compatibility :
- enable dark mode on your favourite websites in their settings
- on YouTube, turn off ambient mode

## Testing

To test the project locally :

1. download the project
2. make your changes
3. go to: about:debugging#/runtime/this-firefox
4. click to "Load Temporary Add-on"
5. select manifest.json
